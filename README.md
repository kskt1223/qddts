# 欣正义供水站

桶装水产品与价格展示网站。客户查看水价、押金和配送说明，通过电话或微信联系门店订水。页面不提供购物车、订水表单、订单记录或管理后台。

## 本地预览

使用 Node.js 22.13 或以上版本，无第三方运行依赖，无需构建。

```sh
npm run dev
```

访问 <http://localhost:4173>。可复制 `.env.example` 为 `.env`，调整 `PORT` 和 `HOST`。

## 维护价格与门店信息

编辑 `public/catalog.json`，保存并刷新页面即可生效：

- `products`：产品名称、分类、价格和容量说明。`price` 单位为分，例如2200表示22元；`null` 表示价格请咨询。
- `settings.phone`、`alternatePhone`：两个订水电话。
- `settings.businessHours`、`deliveryArea`：营业时间与配送说明。
- `settings.deposit`、`deliveryFee`：新桶押金与配送费，单位为分。

目前展示力之泉矿泉水22元、力之泉山泉水17元、刺猬优选17元、淳蓝山泉15元、正义水13元；崂山微矿水为咨询类商品。新桶押金50元/桶，市南、市北、崂山、李沧四区免费配送，营业时间9:00–18:00。

## 维护微信二维码

已接入门店提供的原始二维码 `public/assets/wechat_qrcode.png`，点击悬浮框中的图片会在当前页面居中放大。支持关闭按钮、点击遮罩和 Escape 关闭，图片按屏幕大小等比例展示。

替换时可直接更新该图片，保留文件名。也支持将新图片保存为 `public/assets/wechat-qr.png`（或 `.jpg`、`.jpeg`、`.webp`），并同步修改 `public/catalog.json` 的 `settings.wechatQr` 路径。刷新后生效；图片缺失时会显示占位提示，电话仍可使用。

桌面端右侧常驻电话与二维码悬浮框；手机端通过右下角“联系门店”按钮展开。页头“联系门店”和正文“联系供水站”按钮会居中弹出完整联系方式，支持关闭按钮、点击遮罩和 Escape 关闭；窗口内仍可点击二维码放大。产品图片仍是标注清楚的示意图。

## 检查

```sh
npm test
npm run test:coverage
npm run check
```

使用 `node:test` 验证价格、联系方式、静态资源、无订购表单、旧管理与订购接口不可访问、只读请求及本地文件隔离。覆盖率要求核心服务代码的行、分支和函数至少80%；不包含浏览器脚本与启动入口。`check` 验证 JavaScript 语法。

## 目录与部署

```text
public/     页面、价格配置、样式、脚本和图片
src/        仅提供静态文件的本地预览服务
tests/      展示页面与只读服务验证
```

正式部署可直接将 `public/` 放到静态网站服务器或静态托管平台，并配置 HTTPS。也可使用 `npm start` 提供静态文件。页面不依赖数据库、不生成管理密码、不收集客户订水信息。旧版 `.data/` 不再读取，也不会通过网页提供下载；`AGENTS.md` 保留原样。
